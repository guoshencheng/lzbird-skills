# 可组合的路书风格提示词

根据完整路线和用户偏好选用、组合或另拟下面片段，再放入[出图提示词](share-image.md)的视觉方向。它们不是固定模板，不限制画幅、配色或概览/详细；信息取舍独立决定。只有实际输入明确时才使用季节、亲子、夜游等主题。

| 风格 | 路线线索示例 | 可加入prompt的片段 |
| --- | --- | --- |
| 水彩旅行手记 | 湖畔、公园、江南街巷、自然慢游 | 透明水彩晕染与细铅笔线，温润纸张纹理，小景与文字自然交织，留白充足；配色来自路线景观，轻盈、安静、亲切 |
| 复古城市海报 | 城市漫步、建筑、市井、明确的夜游 | 复古旅行海报与丝网印刷质感，克制颗粒、几何城市轮廓及场景拼贴，醒目标题与清楚的信息组；按实际行程氛围选择日景或夜色 |
| 人文编辑拼贴 | 博物馆、古城、展览、人文路线 | 文化旅行杂志编排，纸片拼贴、票根式信息块与简洁线描；有编辑感、主次明确，不编造真实票据、展品或历史事实 |
| 山野地形图感 | 登山、山地、自驾、多段路线 | 户外旅行视觉，地形感线条、山脊剪影、路标式层级，色彩来自山野；路线线条表达先后，不伪造坐标、导航距离或真实等高数据 |
| 轻松童趣插画 | 明确亲子出游、乐园、动物主题 | 温暖明快的圆润插画，场景贴纸、清楚分日和轻松节奏；不因地点猜同行者身份、年龄或身体能力 |
| 极简路线图解 | 活动密集、跨城、多日、信息优先 | 清爽信息图，少量主题色，时间地点层级清楚，节点易扫读；装饰克制，密集时分组/分图，不缩字、丢项或截断标题 |

可以选择没有列出的风格。色彩跟随路线和创作意图，默认品牌区域使用主参考生成的完整指引卡；有实际分享码时先HTML2Image再附图给模型，原样放入，不重画Logo/小程序码。没有可用卡时仅保留准确文字品牌。不要求全图绿色。

## 编译示例：湖畔慢游

假设两日路线由湖滨集合、沿湖慢走、南山路散步及次日老街/运河活动构成，AI可选择水彩手记和按天概览；若源写09:00集合则必须保留09:00，普通游览时间与非关键备注可按本次用途省略。

```text
生成湖畔慢游路线的水彩旅行手记海报：透明水彩、细铅笔线、温润纸感，湖岸/柳树/街巷小景与文字交织。按原两天分区，每天依原序保留所有活动标题及地点，第一项09:00集合清楚标出。配色取青绿与柔和水色，中文清楚，不用重复网页卡片。为已附的旅账鸟鸟整体指引卡预留清楚区域，整张原样放入，不重画卡内码图/行程码；未提供卡时只做准确文字品牌。精确标题、活动和地点使用本次完整源编译的清单，不直接沿用示例路线。
```

## 编译示例：当日城市夜游

假设只有四项明确时间节点，AI可选择复古夜色海报并保留全部时间。该选择来自源的傍晚/夜间安排，不凭城市名假定夜游。

```text
生成城市傍晚至夜间漫步的复古旅行海报：深靛蓝、暖琥珀灯光和少量朱红，克制丝网印刷颗粒，抽象的街巷/城市灯火形成节奏。全部时间、活动标题和地点相邻成组，依原序展开；插画与文字穿插，不把装饰线当真实地图。为已附的旅账鸟鸟整体指引卡预留清楚区域，整张原样放入，不重画卡内码图/行程码；未提供卡时只做准确文字品牌。具体时间和地名完全使用当前路书清单，不编造交通耗时。
```

风格提示词不改变原行程事实；未给交通/天气/票务信息时不补成已核验建议。按主参考完成原数据→文案→成图检查后交付。
